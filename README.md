# Business Process Improvement Case Study

## Overview

This project explores a fictional vendor approval process and identifies opportunities to improve operational efficiency.

The goal is to analyse the current process, identify bottlenecks and risks, and propose a more efficient workflow supported by measurable KPIs.

## Business Problem

A fictional company is experiencing delays in its vendor approval process. Requests need to go through several teams before a vendor can be fully approved and set up.

The company wants to understand:

* Where are the main delays occurring?
* What factors are contributing to longer processing times?
* What changes could make the process more efficient?
* Which KPIs should be used to measure improvement?

## Process

Current workflow:

**Request → Manager Review → Compliance → Finance → Approval → Vendor Setup**

## Analysis

The analysis will focus on:

* Processing time by stage
* Overall approval time
* Bottlenecks
* Incomplete requests
* Operational risks
* Opportunities for process improvement

## Proposed Solution

Based on the analysis, a redesigned workflow will be proposed to reduce unnecessary delays, improve handoffs between teams, and create clearer process ownership.
